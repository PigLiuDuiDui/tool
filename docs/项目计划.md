# 轻工具箱 — 项目计划

## 产品目标

一站式微信小程序：证件照制作、图片处理、Office/PDF 转换与文档压缩。

视觉：现代简约、清爽明亮、蓝紫主渐变、分类辅色卡片，非后台管理系统风格。

## 一期范围（已实现主路径）

- 首页 / 工具 / 我的 + 统一工具详情页
- 证件照（多规格 + 换底）
- 图片压缩 / 裁剪 / 尺寸 / 格式 / 背景
- Word→PDF、图片转 PDF、PDF 转图片（简化）、PDF 合并/拆分
- Word/PDF **压嵌套图压缩**（借鉴原「文档图片压缩工具」）+ 体积预估
- 微信 mock 登录、日限流、24h 文件清理、处理记录

## 二期

- PDF→Word、Excel/PPT→PDF
- 收藏与反馈工单、付费提额

## 架构

小程序 → Spring Boot(`/api`) → PostgreSQL / Redis → photo-worker / doc-worker

## 旧桌面压缩工具借鉴点

DOCX：`word/media` 抽图再压写回；采样预估；标准/增强预设；拒绝 `.doc`。
